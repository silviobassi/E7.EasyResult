# Clean Code

Reference: Robert C. Martin, Clean Code.

## Guidelines

- Express intent through code.
- Use meaningful names.
- Keep methods focused.
- Eliminate dead code.
- Prefer expressive code over comments.
- Reduce cyclomatic complexity.
- Remove duplication where meaningful.
- Avoid hidden side effects.
- Prefer immutable data when appropriate.

## Flexibility

Small methods are preferred, but readability always comes first.
