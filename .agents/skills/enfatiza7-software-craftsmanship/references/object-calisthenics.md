# Object Calisthenics

Reference: Jeff Bay, Object Calisthenics.

## Interpretation

Apply these rules as heuristics.

## High Priority

- Use one level of indentation when practical.
- Prefer guard clauses.
- Minimize nested `if` statements.
- Keep classes small and cohesive.
- Keep methods small and cohesive.
- Use explicit names.
- Prefer Tell, Don't Ask.

## Medium Priority

- Encapsulate important value objects.
- Encapsulate collections with behavior.

## Low Priority

- One dot per line.
- Two instance variables.

## Never

Do not create unnecessary classes merely to satisfy these rules. Readability always wins.
